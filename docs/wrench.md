# 扳手

所有带 `c:wrenches` 物品标签的扳手共享以下功能，主手和副手均可使用，不消耗物品或耐久。

- 普通右键：旋转带 `diversitycore:wrench_rotatable` 方块标签的方块，成功时不触发原本的方块交互，例如打开容器。
- Shift + 右键：拆卸带 `diversitycore:wrench_breakable` 方块标签的方块，掉落优先进入背包，溢出部分掉在原地。不会回退到旋转。

主手为空、副手拿扳手时，受支持容器的交互会传递给副手进行旋转；主手持有其他物品时保留游戏原有的主手优先规则。

## 旋转顺序

| 朝向属性 | 每次右键的变化 |
| --- | --- |
| 水平 `facing` | 北 → 东 → 南 → 西 → 北 |
| 六面 `facing` | 北 → 东 → 南 → 西 → 上 → 下 → 北 |
| `axis` | X → Y → Z → X |

水平朝向优先调用方块的 NeoForge 旋转方法，允许方块自行调整关联状态；默认不实现旋转的方块按标准水平朝向循环。六面朝向与轴向显式按上表循环。其他属性保持不变，方块实体及其库存保留；服务端检查权限及新状态能否存活，并同步状态和通知邻居。

默认白名单包含熔炉、高炉、烟熏炉、木桶、发射器、投掷器、观察者、普通活塞、黏性活塞及 `minecraft:logs` 标签中的方块。创造电能库没有朝向属性，不参与旋转。

活塞仅在缩回（`extended=false`）时可旋转；伸出时保持原方向，缩回后可再次旋转。活塞头和移动中的活塞不在默认白名单中。

## 数据包扩展

两个方块标签互相独立。扩展旋转白名单时，可在数据包中添加 `data/diversitycore/tags/block/wrench_rotatable.json`：

```json
{
  "replace": false,
  "values": ["example:machine"]
}
```

方块需要使用上述标准朝向属性，并适合单方块状态旋转。无支持属性的方块保持普通交互。第一版不提供门、床、双箱等特殊结构的旋转适配，也不自动联动其他方块；不要将这些结构直接加入白名单。自定义属性需另行适配。

已取消或禁止使用方块、物品的交互不会旋转；旁观模式、冒险模式限制及区域交互权限仍生效。旋转不会发布拆卸用的破坏事件，领地插件应通过右键交互事件阻止旋转。
